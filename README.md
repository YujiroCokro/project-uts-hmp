**Cara Instalasi**
1. Download Node.js
2. di CMD ketik npm install -g @ionic/cli
3. ionic start nama_file blankk --type=angular
4. Pilih Angular
5. Pilih NgModules
6. Pilih no untuk pembuatan free account

**Cara Jalanin Aplikasi**
1. di terminal ketik cd namafile
2. ionic serve

**Fitur**
1. Dashboard: jumlah produk, jumlah transaksi hari ini, dan produk terlaris.
2. Produk: daftar produk, pencarian berdasarkan nama, tambah dan ubah produk (Reactive Form dengan validasi), serta halaman detail dengan animasi.
3. Keranjang: tambah item dari halaman detail (dibatasi sesuai stok), hapus item dengan geser, dan konfirmasi transaksi.
4. Transaksi: riwayat transaksi dan detail item per transaksi.
5. Mode gelap: pilihan tema disimpan di localStorage.
6. Navigasi: menu samping dan tab bawah.
